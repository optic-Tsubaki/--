# FDTD 实验方案代码

- `方案一_旧版单层结构`：单层实验脚本；原始基线保存在 Git `scheme-1-legacy-single-layer` 标签中。
- `方案二_双层结构`：双层模型脚本。

两个目录相互独立；运行时请将所选目录下的脚本分别粘贴到对应的 Lumerical Analysis Group 与 unit group 中。

## 两个模型的分析约定

| 项目 | 方案一：单层 | 方案二：双层 |
| --- | --- | --- |
| 入射方向 | 从上方空气沿 -z 入射 | 从下方 SiO2 沿 +z 入射 |
| T 监视器及透射功率 | 下方 SiO2；`T_total=-transmission(T)` | 上方空气；`T_total=transmission(T)` |
| R 监视器及反射功率 | 上方空气；`R_total=transmission(R)` | 下方 SiO2；`R_total=-transmission(R)` |
| 透射级次投影 | 使用 T 中心介质与功率流方向的默认设置 | 显式使用空气折射率 1、+z 方向，并输出方向余弦 |

以上差别来自现有分析脚本。两个 `unit_group_setup_script.lsf` 当前内容相同，只调整 `TiO2_l1`、`TiO2_l2` 两根柱，不能单凭它们证明双层模型的全部几何结构。仓库没有相应的 `.fsp` 模型文件；使用前需在各自模型中核实对象层级、层数、监视器位置及入射方向。两方案的相位投影介质与方向不同，不能直接把它们的 `phase_target` 数值当作同一参考面下的相位差。

## 单次目标波长仿真

每次光源只覆盖一个目标波长附近的 8 nm 窄带：880 nm 对应 876–884 nm；905 nm 对应 901–909 nm；940 nm 对应 936–944 nm。图示的是**监视器**设置：`use source limits`、默认频率间距、5 个频点。三个波段中最靠近目标的采样点分别约为 879.9818、904.9823、939.9830 nm，均满足脚本的 0.25 nm 容差。T、R 应采用相同的采样设置，T 还要记录 E-field。

分析脚本只接受一次运行中恰好一个目标波长（880、905、940 nm）；若 T/R 采样不匹配，会打印各自最近的采样波长。只有几何、监视器、功率、级次和相位检查全部通过后才输出有效结果；失败时 `T_total`、`R_total`、`eta_target` 为 -1，`phase_target` 为 -10。相位有效范围为 [0, 2*pi)。
